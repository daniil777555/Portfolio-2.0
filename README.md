# Portfolio projects

A collection of projects from the start of my journey learning software development till the nowdays.

## MySQL

[`MySQL/`](./MySQL/) contains exercises from when I was learning database
fundamentals: creating tables and relationships, querying and joining data, and
experimenting with views, stored procedures, functions, and triggers.

## Site constructor

[`site-constructor/`](./site-constructor/) is an early web-engineering project:
a small visual page builder where you can add, style, update, and remove page
blocks, then export the result as HTML.

## Python and machine learning

[`python/`](./python/) holds my Python learning exercises, covering programming
fundamentals as well as concurrency and machine learning. Many models may not show
very good results, as I trained them myself locally. Sometimes I had to gather data,
preprocess, annotate, and clean it before training models.

- [`python/ml/`](./python/ml/) is a collection of experiments with datasets,
  traditional machine-learning methods, neural networks, and reinforcement
  learning.
- [`python/ml/myModels/`](./python/ml/myModels/) contains simple implementations
  of algorithms such as KNN, linear and logistic regression, Naive Bayes,
  k-means, PCA, perceptrons, and SVMs, written to understand how they work.
- [`python/ml/Tenserflow/`](./python/ml/Tenserflow/) contains TensorFlow
  projects, including image classification, face detection, iris tracking,
  audio classification, toxic-comment classification, and lip-reading.
  Reinforcement-learning experiments include agents trained to play games.
- [`nn-in-web/`](./nn-in-web/) runs an image-classification model directly in
  the browser with TensorFlow.js. Images are processed client-side, without a
  server running the model.

## Spy Game

[`spy-game/`](./spy-game/) is my most recent project: an online version of a
social-deduction table game. Create a room and invite friends; players answer
the same question while the spy has a hidden role, then everyone votes on who
they think the spy is.
